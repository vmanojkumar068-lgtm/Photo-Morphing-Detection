# MorphGuard — Photo Morphing & Tampering Detection

## 📌 Project Overview

MorphGuard is a browser-based image integrity screening website designed to help users examine photos for potential signs of digital manipulation, face morphing, and AI-generated image provenance. It provides an interactive interface that analyzes selected images and presents screening results.

## ✨ Key Features

* **Image Upload:** Upload or drag and drop images in JPG, PNG, and WEBP formats.
* **Digital Manipulation Screening:** Examines pixel patterns, compression artifacts, noise, and edges.
* **Face Morphing Screening:** Checks facial symmetry and localized blending patterns.
* **AI Provenance Checks:** Looks for AI-generator information and Content Credentials in available metadata.
* **Visual Analysis:** Displays an image preview and an error-level evidence map.
* **Screening Report:** Presents assessment indicators, a score, and image details.
* **Image Information:** Displays file format, dimensions, file size, and metadata indicators.
* **Responsive Design:** Provides a user-friendly interface for desktop and mobile screens.
* **Browser-Based Processing:** Designed to process images locally in the browser.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML Canvas API

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Open `index.html` in a modern web browser.
4. Navigate to the image analysis section.
5. Upload an image and review the screening report.

No Python environment or model training is required to open the current HTML-based version.

## 🎯 Project Objectives

* Demonstrate image integrity screening through a web interface.
* Help users explore potential signs of photo manipulation and morphing.
* Present image analysis indicators in an understandable format.
* Raise awareness of digital image authenticity and forensic analysis.

## ⚠️ Disclaimer

MorphGuard is an educational image screening project. Its indicators and scores are not definitive proof that an image is genuine, morphed, or manipulated. Results should be independently verified before making important decisions.
